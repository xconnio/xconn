# Changelog

## 0.1.0

- Initial blocking and asyncio Python clients backed by the shared Rust runtime.
- Fluent WAMP RPC and publish/subscribe, authentication, and progressive calls/results.
- Direct QUIC, WebTransport, and WebRTC connections with raw streams/channels.
- PyO3 extension targeting the CPython 3.10+ stable ABI, with no required Python dependencies.
